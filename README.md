# 초구, 칠 것인가 볼 것인가

KBO 2025 정규시즌 전체 투구 데이터로 "이 상황에서 초구를 치는 게 나은가, 보내는 게 나은가"를 분석한 프로젝트다.
인하대학교 데이터사이언스 프로그래밍(2026년 2학기) G조 팀 프로젝트.

## 1. 질문

초구 타율처럼 '친 공의 성적'만 보면 치지 않았을 때와 비교할 수 없다.
이 프로젝트는 초구 결정이 내려진 타석 전부를 대상으로, 같은 위치의 공끼리
'쳤을 때'와 '지켜봤을 때'의 득점 가치를 비교해 결정표를 만든다.

- Q1. 공 위치(한가운데·경계·바깥)별로 치는 것과 보내는 것 중 무엇이 나은가
- Q2. 그 답이 아웃 수와 주자 상황(주자 없음, 1루만, 득점권)에 따라 달라지는가
- Q3. 투타 매치업과 투수별 초구 성향에 따라 달라지는가

## 2. 데이터

- 출처: 네이버 스포츠 문자중계 (경기별·이닝별 JSON)
- 범위: 2025 KBO 정규시즌 720경기, 투구 217,849개, 타석 56,152개
- 분석 단위: 1행 = 1타석의 초구 (55,858행)
- 원본 데이터는 용량(약 3GB) 때문에 저장소에 포함하지 않았다. 아래 실행 방법으로 다시 받을 수 있다.

## 3. 실행 방법

```
pip install -r requirements.txt
python check_naver.py        # 네이버 연결 확인
python main.py collect       # 720경기 수집 (약 2시간) 후 분석까지 실행
python main.py               # 이미 받은 데이터로 분석만 실행
```

결과는 results 폴더에 csv와 그림으로 저장된다.

## 4. 코드 구성

| 단계 | 파일 | 하는 일 | 설명 담당 |
|---|---|---|---|
| 1 수집 | step1_collect.py, check_naver.py, check_relay.py | 경기 목록과 경기별 문자중계 JSON 저장 | |
| 2 파싱 | step2_parse.py | JSON을 이벤트·투구 추적·선수 표로 변환 | |
| 3 타석 | step3_pa.py | 타석 테이블, 유령 타석 제거, 타석 결과 분류 | |
| 4 투구·존 | step4_pitch.py | 투구 전 카운트, 공 높이 계산, 존 경계 찾기, 3구역 분류 | |
| 5 기준표·분석표 | step5_value.py | 기대득점표(RE24), 득점 가치, 초구 분석 테이블 | 하상현 |
| 6 분석·시각화 | step6_analysis.py | 결정표, 경기 단위 부트스트랩 신뢰구간, 그림 | |
| 공통 | config.py, main.py | 설정값, 전체 실행 순서 | 하상현 |

로직은 수업 범위(for문, if문, dict, list, 함수, math, random)로 작성했다.
수업 밖 도구는 curl_cffi(웹 요청), json·파일 입출력이다.

## 5. 주요 결과 (2025 정규시즌 전체)

Q1. 공 위치별 결정표 (타석당 득점 가치, 치면 - 보내면, 95% 신뢰구간)

| 초구 위치 | 스윙률 | 치면 | 보내면 | 차이 | 판정 |
|---|---|---|---|---|---|
| 한가운데 | 43% | -0.003 | -0.041 | +0.039 [+0.023, +0.053] | 치는 게 유리 |
| 경계 | 26% | -0.041 | -0.001 | -0.039 [-0.058, -0.024] | 거르는 게 유리 |
| 바깥 | 9% | -0.085 | +0.051 | -0.135 [-0.164, -0.109] | 거르는 게 유리 |

- 바깥 초구는 상황 9칸 중 8칸에서 거르는 게 유리했다(나머지 1칸은 표본 부족).
- 한가운데 초구는 9칸 모두 치는 쪽이 우세했고, 이닝 선두타자(무사 주자 없음)는 치는 게 유리한데도 스윙률이 34%로 가장 낮았다.
- 투타 같은 손/반대 손 모두 결론이 같았다.
- 선발투수의 초구 존 안 비율은 51%~63%로 차이가 있어, 투수에 따라 초구를 노릴지 기다릴지 정하는 근거가 된다.

## 6. 한계

- 관찰 데이터이므로 결론은 "이 조건에서 초구 스윙이 더 나은 결과와 연관되었다"는 수준이다.
- 같은 위치의 공끼리 비교했지만 타자 실력 차이는 통제하지 못했다.
- 상황별 결정표는 27칸을 동시에 비교하므로 일부 칸은 우연히 유의하게 나올 수 있다. 칸 하나보다 같은 방향으로 모이는 패턴을 근거로 해석했다.
